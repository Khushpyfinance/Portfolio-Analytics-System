# Portfolio Analytics System

A portfolio analytics system built with Python, SQLite, Excel, and Power BI.

## Features
- Portfolio input and tracking
- Live price fetching with yfinance
- SQL-based storage
- Excel reporting
- Power BI dashboard visualization

## Tech Stack
- Python
- SQLite
- Pandas
- yfinance
- Excel
- Power BI
